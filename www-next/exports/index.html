Machine-readable files

SummaryEvery machine-readable file this node publishes, what each is for, and which are pinned by a rule.

Everything a program needs from this node is a static file it can fetch without a key, an account or a request to anyone. Start at the discovery document; everything else is reachable from it. The two files under /exports/ are additive: no rule pins their bytes, nothing depends on them, and they exist because they are cheaper to read than the files they are derived from.

FileMedia typeWhat it is
/.well-known/knowledge-linksetapplication/linkset+jsonThe one file to fetch first: it says what this node is, where its graph, ontology, skills and NOW page are, which nodes it peers with, and how to propose a change.
/llms.txttext/plainThe node in one page, for a model with a small context: a title, a provenance header and one line per item.
/llms-full.txttext/plainThe same, with every item's whole body.
/search.jsonapplication/jsonThe search index a page or an agent searches offline, the same bytes the engine emits.
/graph.jsonldapplication/ld+jsonEvery item as RDF, in JSON-LD.
/graph.nqapplication/n-quadsThe same graph as N-Quads — the form its fingerprint is taken over.
/graph.ttltext/turtleThe same graph as Turtle, for a reader.
/chunks.jsonlapplication/jsonlOne line per passage, each with its digest, its item, its licence and its IRI: what a retrieval system indexes when it wants to cite what it found.
/pages/<slug>.mdtext/markdownThe source file of one item, exactly as it is stored.
/pages/<slug>.jsonldapplication/ld+jsonOne item as RDF, on its own.
/skills/index.jsonapplication/jsonThe skill packs and their digests.
/now.mdtext/markdownThe state of this node at the last build.
/ledger.jsonlapplication/jsonlThe derived ledger: one hash-chained line per commit of this site's history and one for the build, re-verifiable offline. Its head is on the ledger link of the discovery document.
/ns/context.jsonldapplication/ld+jsonThe JSON-LD context the graph files use.
/exports/chunks-index.toontext/plainThe metadata of every passage in TOON tabular form — the same rows as /chunks.jsonl without the bodies, in about a quarter fewer tokens. Additive and non-normative.
/exports/llms-ctx.txttext/plainA skim view: one labelled section per passage. It drops the digests, the licence and the IRIs on purpose, so anything that needs to cite goes back to /chunks.jsonl. Additive and non-normative.
/robots.txttext/plainWho may crawl, and the text-and-data-mining reservation, in the crawler dialect.
/.well-known/tdmrep.jsonapplication/jsonThe same reservation, in the TDM dialect.
/sitemap.xmlapplication/xmlEvery page of this site.

Tools inside the page

Every item page and every guide page of this site also offers seven tools to an assistant running in the visitor's browser: search, read, links, ask, compose, propose and remember. They read only the files above, contact no other host, carry no key and write nothing. How they work, and the page that uses them.
