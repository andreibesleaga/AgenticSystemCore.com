Skill packs

SummaryThe skill packs this node publishes: one per cluster, each a single SKILL.md an agent runtime can load, with a lockfile of their digests.

A skill pack is one file. It gathers a cluster's items into the form an agent runtime loads, and it is generated from the same items the pages above show — nobody writes a pack by hand. The index beside them is also the lockfile: it carries the SHA-256 of every pack, so a runtime can tell that what it loaded is what was published.

  • guides: Procedures for publishing and reading a node, each step naming the rule or the check that proves it. (1 item)
  • project-board: The open work on the specification itself, kept as task items of this node, so the project's own plan is published the way the live board publishes any team's. (1 item)
  • vocabulary: The terms of the specification's ubiquitous language: the six item types and the words that complete them. (12 items)

Machine views: /skills/index.json, the index and the lockfile.
