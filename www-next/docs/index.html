Guide

SummaryThe plain-language layer of this site: what AgenticSystemCore is, the six ways it is used, how it works, and how to read the specification without being a standards expert.

The specification is written for implementers and is exact by design. This guide is written for everyone else. Every page here explains; none of them decides. Where a guide page and a rule disagree, the rule wins, and each page names the rules it explains with small references like (AGSC-06-07) that link to the rule text.

Reading paths

  • New here? Read the introduction, then the six modes, then how it works.
  • Architect or engineer? Start with the data model and the architecture, then the requirements and the scenarios.
  • Implementing the standard? Read how to read the specification, then the specification itself, the discovery profile and the ontology.
  • Checking legal, security or policy questions? Go to standards and references and compliance and security.
  • Looking for something specific? Use the search, which covers every page and every rule of this site.
