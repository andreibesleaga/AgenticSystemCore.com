Privacy

This site sets no cookies, uses no analytics and loads nothing from any other host. Its only script is the same-origin search on the search page, which reads an index built with the site and sends nothing anywhere. It collects no personal data.

It does publish some. Every item names the person accountable for it, as the identifier human:andreibesleaga, in its page, its provenance record and the machine-readable views; the author's name and ORCID iD appear on every page. Contributions arrive as pull requests, so a contributor's name, the address they commit under and the sign-off line this project's specification requires become part of the public history of the repository on GitHub — not of this site.

The site is served by Cloudflare Pages. To deliver and protect it, Cloudflare processes the technical data of each request, such as the IP address, the requested address and the user agent, under its own privacy policy and its own retention periods. The operator runs no server and receives no per-request logs; what Cloudflare shows the operator is aggregate, such as how many requests the site served, from which countries and with which status codes.
