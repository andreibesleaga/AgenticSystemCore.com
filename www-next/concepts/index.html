Vocabulary

SummaryThe twelve terms of the specification, each on its own page with the rules that define it.

The concepts of this node: the terms of the specification's ubiquitous language.

  • Bundle: One directory tree of Markdown items plus exactly one agsc.config.json: the unit of publication and of conformance.
  • Cluster: A navigational grouping of items. Membership is authored on the item, and nesting is expressed as membership.
  • Concept: A unit of knowledge in a Bundle, qualified by kind: pattern, taxonomy, explainer, principle, decision, spec, task, term or architecture.
  • Episode: A recorded occurrence, such as a session, a run or an incident, with a start instant, an actor and an outcome.
  • Gate: A declared set of checks that a change must pass, at level L1 or L2. Its runs are recorded as episodes.
  • Harness: Generated output: the file map a valid composition of selected items produces. A Harness is never authored.
  • Item: One Markdown file with YAML frontmatter whose type is concept, episode, procedure, lesson, cluster or gate.
  • Lesson: Knowledge distilled from one or more episodes, carrying a severity of info, warn or block.
  • Link: A typed relation between two items of one Bundle, written as a frontmatter key whose values are slugs.
  • NOW: Generated context about the current state of a Bundle, such as counts and last build. NOW is never an item.
  • Procedure: A plan a reader can execute: a trigger, steps and checks. A procedure exports one to one to a skill file.
  • Source: An external work cited by an item, written inline as a sources[] entry and published under a fragment IRI.
