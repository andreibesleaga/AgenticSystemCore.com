AgenticSystemCore vocabulary 1.0.0-draft.1

SummaryThe vocabulary the graph uses: every class and property with its definition, in Turtle, JSON-LD, RDF/XML and N-Triples.

Vocabulary for AgenticSystemCore Bundles: six item types plus Bundle, Source, Proposal, Review, Harness and (rc.3) Attachment, aligned to SKOS, PROV-O and DCTerms.

Namespace
https://w3id.org/agentic-system-core/ns#
Version IRI

Terms
12 classes, 19 object properties, 21 datatype properties

Profile
OWL 2 RL (AGSC-05-22)

Representations

  • Turtle, text/turtle: the normative source.
  • JSON-LD context, application/ld+json, generated from the Turtle (AGSC-06-32).
  • RDF/XML, application/rdf+xml, and N-Triples, application/n-triples, both generated from the Turtle. Most browsers download these two rather than showing them.

Once the w3id.org redirects are registered, the namespace IRI will negotiate between these representations (AGSC-06-06). This is the copy of version 1.0.0-draft.1.

asc:AttachmentAttachmentA media file carried by an item under content/attachments/<slug>/ (AGSC-02-98); IRI <item-IRI>#attachment-<n> (AGSC-05-29). Pattern images are SVG only.rdfs:subClassOf prov:Entity

asc:EpisodeEpisodeA recorded occurrence — a session, run or incident — with a start, an actor and an outcome.rdfs:subClassOf prov:Activity
asc:GateGateA declared set of checks that a change must pass; its runs are Episodes.rdfs:subClassOf prov:Plan
asc:HarnessHarnessA generated bundle of files assembled from a validated composition of Concepts; never authored, never stored under content/.rdfs:subClassOf prov:Plan
asc:LessonLessonKnowledge distilled from one or more Episodes, carrying a severity; a Concept by essence.rdfs:subClassOf asc:Concept
asc:ProcedureProcedureAn executable-by-a-reader plan: trigger, steps and checks. Exports one-to-one to a skill file.rdfs:subClassOf prov:Plan
asc:ProposalProposalA proposed change to a Bundle. It has no file: it is a forge pull request, instantiated in exports from the derived git log.rdfs:subClassOf prov:Activity
asc:ReviewReviewThe human assessment of a Proposal. It has no file: it is instantiated from a verified[] entry at the IRI <item-IRI>#review-<n>, its actor and instant carried by asc:verifiedBy and asc:verifiedAt (AGSC-05-15).rdfs:subClassOf prov:Activity
asc:SourceSourceAn external work cited by an item. It has no file: it is instantiated from a sources[] entry.rdfs:subClassOf prov:Entity
