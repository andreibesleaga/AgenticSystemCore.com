> **In short**
>
> - This page lists every standard, draft and profile the extension reads or uses, and what it does with each. Status was read on 14 Nov 2026.
> - The extension reads these files. It does not claim to support, conform to or certify any of them.
> - WebMCP is a draft (Draft Community Group Report, 13 Nov 2026). It is not a W3C Standard and not on the W3C Standards Track.
> - Status words: standard (an RFC or a W3C Recommendation), draft, the AgenticSystemCore project's own profile, and convention.
> - It deliberately does not read VoID and DCAT files, an MCP server card or the skills index: no fixed path exists, or the address would come from a file.

This page lists every standard, draft and profile that WebAIAssist reads or uses, what it does
with each one, where in the code, and what it does not do. Status was read on 14 Nov 2026; the
sources and dates are in SOURCES.md. The plain-words pages are
[What is WebMCP](/webaiassist/what-is-webmcp/) and [What the extension reads](/webaiassist/what-the-extension-reads/).

WebAIAssist reads these files. It does not claim to support, conform to or certify any of them.

## How to read the Status column

| Status                                      | Meaning                                                                                                                                                                    |
| ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| standard                                    | An RFC (the IETF's number is given, with its own level: Proposed Standard or Informational) or a W3C Recommendation.                                                       |
| draft                                       | Not final. The body and the date of the draft are given. A Community Group draft is not a W3C Standard and is not on the W3C Standards Track; the document says so itself. |
| the AgenticSystemCore project's own profile | A format of the AgenticSystemCore project, by the same author as this extension. Not a standard of any body.                                                               |
| convention                                  | A format that many sites use but no standards body owns.                                                                                                                   |

## What the extension reads from a site

Every address is the open tab's own site plus a fixed path. A path that comes from a file is used
only in the two cases marked "named by the link set" (see the end of this page). All text read is
untrusted data. The nine fixed files are in `src/core/site-files.ts`.

## What the extension reads from an AgenticSystemCore node (named by the link set)

Only for a node whose own link set names the file on the node's own site with a SHA-256 digest, and
only when the bytes match that digest. A file that is cut, too big, of the wrong type or different from
its digest is refused whole.

## Files the extension can read but does not use

Neither of the two nodes that were checked (agenticsystemcore.com and patterns.agenticsystemcore.com)
publishes an API catalog or an agent card; for those two files the card says "not published".
The extension does not read, on purpose: VoID and DCAT files, a SPARQL service description, an MCP
server card, OpenSearch descriptions, the IETF AI-preferences drafts, JSON Schema files of a site, chunk
and TOON files, the skills index and the ledger. For each, either no fixed path exists, or the address
would have to come from a file. Next-release candidates are in ../ROADMAP.md.

## Statements this page does not make

- It does not say that the extension supports "every standard". It says which files it reads.
- It does not say that WebMCP is a standard. The specification says it is not a W3C Standard and not
  on the W3C Standards Track.
- It does not say that a site, node or tool was checked against any of these documents.
