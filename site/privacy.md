This site sets no cookies, uses no analytics and loads nothing from any other host. Its scripts are all served from this site, and none of them sends anything anywhere: the search on the [search page](/search/), which reads an index built with the site; the [compose page](/compose/), which works in your browser and uploads nothing; the in-page tools on item and guide pages, which answer an assistant running in your own browser from this site's own published files; and the theme control on every page. If you pick light or dark, that choice is kept in your browser's local storage under the one key `agsc-theme`; it is never sent anywhere, choosing Auto removes it, and clearing this site's data in your browser removes it too. It collects no personal data.

It does publish some. Every item names the person accountable for it, as the identifier `human:andreibesleaga`, in its page, its provenance record and the machine-readable views; the author's name appears on every page, and the [ORCID iD](https://orcid.org/0009-0001-3464-5283) on the [About page](/about/). Contributions arrive as pull requests, so a contributor's name, the address they commit under and the sign-off line this project's specification requires become part of the public history of the repository on GitHub — not of this site.

**Why.** The names are published so that every statement on this node can be traced to a person who answers for it — that is what the whole project is about — and so that contributions can be attributed to the people who made them. The footing for publishing them is the operator's own interest in running an accountable, attributable public record of technical work, and the public interest in being able to check who said what. Anyone named may object, and what happens then is set out below. Nothing is used for advertising, for profiling, or for any purpose other than the one stated here.

The site is served by Cloudflare Pages. To deliver and protect it, Cloudflare processes the technical data of each request, such as the IP address, the requested address and the user agent, under its own privacy policy and its own retention periods. The operator runs no server and receives no per-request logs; what Cloudflare shows the operator is aggregate, such as how many requests the site served, from which countries and with which status codes. The source of this site is kept on GitHub, so the repository's history — including a contributor's name, the address they commit under and their sign-off line — is held and published by GitHub under its own terms.

**Your rights.** If personal data about you is published here, you may ask to see what there is, to have it corrected, to have it erased, to have its use restricted, and to object to it being published at all. Use the contact route below and you will get an answer. One limit has to be said honestly: the published history of the repository cannot be rewritten without destroying the record that makes this work checkable, so an erasure request against a name that is already in that history will usually be answered by removing the name from the site and from every export, and by explaining why the history itself stays. If you are not satisfied, you may complain to the Romanian supervisory authority, the Autoritatea Națională de Supraveghere a Prelucrării Datelor cu Caracter Personal ([dataprotection.ro](https://www.dataprotection.ro/)), or to the authority where you live.

Some of the names published here — the authors of the work the items cite — were never contacted, because there are too many of them for that to be reasonable. This notice is how they are told. They have the same rights, and the same contact route.
