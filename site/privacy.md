This site sets no cookies, uses no analytics and loads nothing from any other host. Its only script is the same-origin search on the [search page](/search/), which reads an index built with the site and sends nothing anywhere. It collects no personal data.

The site is served by Cloudflare. To deliver and protect it, Cloudflare processes the technical data of each request, such as the IP address, the requested address and the user agent, under its own privacy policy. The operator of this site does not receive or keep request logs.
