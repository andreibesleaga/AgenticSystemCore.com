Each feature file listed below has a page of its own and is a frozen artefact of the project's requirements phase, published here for the specification version this site publishes. The scenarios are written so that every step is executable: a concrete command, a route, a tool call or a file, never "the system behaves correctly". Tags of the form `@PRD-nnn` link a scenario to a row of the [requirements page](/docs/requirements/); a few steps name rules of the specification.

The scenarios describe the reference engine and the content site at general availability. Where a scenario names a surface that this Level-0 site does not serve as a page, the [status page](/docs/status/) says what is live today: the local tool server (`agsc mcp`) is not a page of this site; the combiner page and the skill packs are.
