# AgenticSystemCore.com

Content and static site of the first public **AgenticSystemCore** instance (agenticsystemcore.com): a Bundle of agentic-system-pattern Concepts, Clusters, Procedures and Lessons, compiled by `agsc` (npm `agentic-system-core`) into a static site, RDF graph exports, `llms.txt`, `/.well-known/agentic-knowledge`, Skill packs and a generated NOW page. CI is the only backend (`npx agsc ci`); Cloudflare serves static files.

Status: pre-launch (target 2026-10-10). Layout, config and workflows are generated by `agsc init` (see the engine repo). Prose: All Rights Reserved + Content Use Terms v1; schema/ontology CC0; code Apache-2.0.
