NOW

SummaryGenerated context about the current state of a Bundle, such as counts and last build. NOW is never an item.

Type
concept · kind term
Cluster

Provenance
Written with AI assistance and reviewed by the operator (origin ai-assisted, operator human:andreibesleaga)

NOW is generated context: counts, the last build, stale items, open Lessons and monthly spend. It is produced from stored state only and is never hand-edited; a section whose input is absent is omitted, not guessed.

NOW is never an item.
