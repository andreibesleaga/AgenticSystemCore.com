Recipes

SummaryShort task pages: one job each, about ten minutes, every command with the lines it prints. Bring knowledge in from other formats and tools, connect assistants, check and trust a node, and extend the engine.

A recipe covers one job from an empty folder to a result you can check. The guides explain each of the six modes at length; a recipe is the short page for the day you need one thing done.

Every command on these pages was run with engine 1.1.0, and the lines quoted under it are the lines it printed. Each page has a script in the site's repository that repeats all of its commands, so anyone can run the page again.

How these pages are kept true

Each page states what it does not do, and says where a step was not run (for example, inside another company's product). The pages will move into the engine's tested guides at its next version; until then the scripts in the repository are the check.
