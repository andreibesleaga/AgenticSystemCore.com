This board is the project's own record of what is still to be done, published by the same rules it describes. Each task is a Concept of kind task with its state; the machine view of the board is /boards/project-board.json, and /boards/index.json lists every board of this node. People and agents change a task only by proposing a change to its file, which a person reviews.
