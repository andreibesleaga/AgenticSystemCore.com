Clusters

SummaryThe groupings this node uses to organise its items.

The navigational groupings of this node.

  • Guides: Procedures for publishing and reading a node, each step naming the rule or the check that proves it.
  • Project board: The open work on the specification itself, kept as task items of this node, so the project's own plan is published the way the live board publishes any team's.
  • Vocabulary: The terms of the specification's ubiquitous language, the six item types and the words that complete them.

How the clusters connect

No relation joins the members of two different clusters; each cluster's page shows the links among its own members.

The fourteen relations

The relations an item can state, as the relations tables and figures of this site name them, with the name each reads by from the other end.

RelationRead backwardsMeaning
relatedrelated (both ways)The two items are connected in meaning, and neither depends on the other.
broadernarrowerThe target is a wider subject that this item falls under.
narrowerbroaderThe target is a more specific subject that falls under this item.
usesused-byThis item draws on the target and can still be used when the target is absent.
requiresrequired-byThis item cannot be used without the target, so choosing this item also takes the target.
excludesexcludes (both ways)This item and the target cannot be used together.
derived-fromderivation-ofThis item was produced from the target, which is its origin.
contradictscontradicts (both ways)This item and the target make claims that cannot both be true.
supersedessuperseded-byThis item replaces the target, which stays published but is no longer the one to use.
implementsimplemented-byThis item puts the target into practice, as code or a procedure puts a specification into practice.
verifiesverified-byThis item checks that the target holds.
coverscovered-byThis item covers the target, as a test or a document covers a requirement.
blocked-byblocksThis item cannot go ahead until the target is resolved.
decided-bydecidesThe target is the decision record that settled this item.

Explore the graph

Every published item and the links among them, as a picture. Select an item in the list or in the picture to see its relations and what each means. In the list the arrow keys, Home and End move, Enter selects, and Escape closes the tooltip, then clears the selection.

This site also has an explorer of its own, the graph explorer: it draws the same graph with the graphs of the peer nodes this node names, in 2D or 3D.
