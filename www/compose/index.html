Compose

SummarySelect items from this node and compute a Harness in the browser; the same page offers the ten tools to a browser assistant.

Tick the items you want. The composition rules of the specification (AGSC-07) run in this page: no request leaves this origin, no key is needed and nothing is uploaded. The seven Harness files are offered one download per file, or all together as one .zip, and the brief of the composition is shown and offered the same way (AGSC-07-25).

This page also offers the ten tools of AGSC-09-13 to a browser assistant that supports them, as every item and guide page does. See Tools for browser assistants.

This page composes in the browser and needs JavaScript; the same result comes from agsc compose.
