Brief Desk

SummarySearch, cite and later re-check the passages knowledge nodes publish, by hand or with an assistant that runs in your browser and asks before it changes your brief or contacts another site.

Try it now, with no key

For anyone who quotes a published page and needs to know later whether it still says the same. The buttons read only files this site publishes; nothing leaves your browser.

  2. adds it to your brief after checking its text against the digest the site published.

            How this page works

            • The agents are published data. The network of two agents is the file brief_desk.network.json, named by agent-manifest.json; its instructions are public. Another agentic website can load it by the address https://agenticsystemcore.com/desk/brief_desk and run it in its own visitor's browser.
            • The agents run in your browser. The runtime in /desk/runtime/ is the open-source browser runtime of the Open Agentic Web project, unchanged. Model calls go from your browser to the provider you choose, with your key, which stays in this browser's storage for this site.
            • What the agents can do here is this page's own list. Eight actions: read the page's state, search passages, read one passage and check its digest, check the brief again, check citations someone saved, add a card, remove a card, discard the brief. Each change to your brief shows you what it changes and asks first. Another site that runs this network gets three of them, search, read with the digest check and the check of saved citations, over this node's published passages only.
            • What the checks show. A node publishes each passage with the SHA-256 digest of its text in /chunks.jsonl, and the digest of that whole file in its discovery document, /.well-known/knowledge-linkset. The page compares the file with the one digest and each passage with the other, and adds a card only when they agree. Both digests come from the same site as the text, so a match shows that the node's files agree with each other and arrived whole; it does not show that the text is true. The check that does not depend on the node comes later. A brief keeps each card's digest, so Check the brief again, or Check a saved brief on a brief someone sent you, shows which cited passages the node has changed since.
            • Other sites are asked only with your consent. The page reads another node's passages after you tick it. The assistant can also ask the assistant of patterns.agenticsystemcore.com or standards.agenticsystemcore.com; a card names the site and shows the request before anything is sent. The assistant can also ask that site to write a proposal that corrects one of its cards. That site then opens its own window, where you read the proposal and type your name and your reason; the chat here gets back a reference and a one-line summary, never what you typed, and nothing is published until you send the proposal to that site's maintainers.

            More from this node

            • The graph explorer draws the same items as a typed graph, with the peer nodes when you ask, so you can see what a cited passage connects to.
            • The vocabulary names the terms the items use, as published linked data.
            • WebAIAssist, a browser extension by the same author, runs a small model on your own computer with no key. On this page, as on the site's other pages, it can use the page tools the engine offers (search, read and cite this node), and asks you before each one.

            The page works without the assistant, and without a key: the search form and the brief use the same code the assistant calls. The source is in the site's repository, under Apache-2.0.
