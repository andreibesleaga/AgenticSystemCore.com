AGSC-01 — Bundle: files, folders, encoding, configuration

SummaryThe directory that holds a node's knowledge: its layout, slugs, encoding, the one configuration file, the optional agent-lane declarations, and how foreign content comes in and goes out.

Status of this document

Specification 1.1.0, released and tagged on 2026-11-13. It is an independent specification: it is not a standard of the IETF, the W3C or any other body, and no standards body has reviewed or adopted it. Released sections are immutable; a correction ships as a new version.

Part 2 of 2, 1.7 to 1.9. This section is published in two parts so that each page stays within the budget of AGSC-06-21; a rule's link names the part that carries it. Part 1 carries 1.1 to 1.6.

In plain language

The directory. content/ holds the items in type folders, content/attachments/<slug>/ holds media, and agsc.config.json is the single configuration file. Nothing else is required.

Names. Every item has a slug: lowercase letters, digits and single hyphens, 1–64 characters, unique in the Bundle. The slug is the file name and the last part of the item's web address.

The configuration file. It is closed: a key the specification does not name is an error, except vendor keys that start with x-. It carries the site base URL, licences, tag lists, release switches, peers, channels and the boundary parameters (federation, chunks, contribute, visibility, attachments), each with a default and a maximum.

Import. A folder of bare Markdown can be adopted with one command; unknown frontmatter keys are kept and reported as warnings, never errors.

Export. Markdown, JSON-LD and JSONL exports are lossless round trips; the prose exports carry the Content Use Terms, or the prose licence the node names in their place.

Channels. Messages from a mailbox or a chat can become proposals, under guards: a sender list, a rate, a cap on open proposals, injection checks.

Diagrams. A .diagram file in a small fixed language compiles to the same SVG on every machine; from 1.1 an arrow, line or text may name the Link key it stands for (rel=KEY).

From 1.1, the configuration may add a domain layer (domain): the node's own classes and relations, rules its items must keep and questions its graph must answer, and its bounded contexts. A node without it builds as before. site.query_page switches the query page off.

Paths. A relative path never contains .., . segments, a leading slash, a backslash or a NUL, and always resolves inside the Bundle.

Agent lanes. The configuration may declare agents: a name, a kind (model or program), the forge identity and the accountable person, the model, what it may do, which item types it may touch, the channel its proposals go through, a schedule, a monthly budget, how many items one proposal may create (default twenty) and how many tasks it may hold at once (default one). Disabled unless switched on. The whole node has one cap on model spend of every kind, ten dollars a month unless changed, and the agents' budgets may not add up to more. Anything host-specific or secret — the cap, an agent's switch or budget, the model key — can be set in a .env file in the Bundle root that is never committed; init lists the recognised names in .env.example.

This box explains; the rules below decide. New to the notation? See how to read the specification.

1.7 Channel ingest

  • AGSC-01-30 A Channel adapter (channels/<name>/) MUST expose pull(since) → messages[] and render(message) → { path, frontmatter, body } producing a conforming item (AGSC-02) under content/<type-plural>/; it MUST NOT write to the content branch directly — ingestion always yields a Proposal (AGSC-08-01..). The CI ingest job pushes the Proposal branch and opens the pull request with the ingest credential CHANNEL_TOKEN_<name>, a fine-grained token scoped to the content repository with contents: write and pull-requests: write, never GITHUB_TOKEN and never in a fork context. Forge fine-grained tokens are not ref-scoped — their permissions are repository-wide — so the branch ruleset, never the token, is what prevents a direct push to the content branch, and the ingest identity MUST NOT appear as a bypass actor on that ruleset (AGSC-08-26(f) gives the separate merge credential that MAY). propose itself still performs no network write (AGSC-08-04). The job MUST reject a message whose sender is absent from a non-empty channels[].allow[], reporting AGSC-E203 (a value outside a closed operator list), and MUST stop for the current hour once channels[].rate{per_hour} messages have been ingested (AGSC-01-18), recording the skipped messages by sources[].id for the next run. render MUST redact e-mail addresses and telephone numbers from the body (AGSC-08-16) and record the sender only in sources[0]. A channel MUST NOT have more than five open Proposals at once; the ingest job MUST stop opening pull requests at that bound and record the skipped messages by sources[].id for the next run (idempotence, AGSC-01-33). (Amended 2026-10-10 for 1.0.0: the rejection named no code) [PRD-043, PRD-056]
  • AGSC-01-31 Each channel declares publish: auto | hitl (default hitl) in agsc.config.json (channels[]). In hitl the Proposal waits for the author's verified[]; in auto it MAY be merged only under AGSC-08-26, whose guard is verified against configuration and forge identity, never against self-declared frontmatter: the pull-request author MUST equal channels[].author, prov.operator MUST equal channels[].owner, and every ingested item MUST carry prov.agent (the adapter id) with prov.origin: imported — so the agent-safety lints of AGSC-08-13 run at error severity (AGSC-08-13) instead of warning. [PRD-056, AGSC-08-05, AGSC-08-26]
  • AGSC-01-32 Optional AI correction in auto mode is limited to formatting/frontmatter/typo repair; it MUST NOT add claims, links or Sources, MUST run under the configured spend cap (NFR-11) and MUST record its spend by adding to the same Proposal one episode item carrying usage{model, tokens_in, tokens_out, cost_usd, estimate} (AGSC-02-14) and prov.agent = the adapter id — the same mechanism AGSC-09-14a requires of an LLM responder, and the only one AGSC-08-25's monthly rollup can see, since a Proposal has no file (AGSC-00-06) and the ledger has no proposal kind at 1.0 (AGSC-08-21). A correction whose spend cannot be recorded MUST NOT run. Without a key the adapter still works (lint-only). [PRD-056]
  • AGSC-01-33 Ingested messages MUST be de-duplicated by a stable source_id kept in sources[].id (a member of the source object, AGSC-02-10); re-ingesting is a no-op (idempotent), and the original channel/message reference is the item's first Source. A channel message that has no web URL uses the resource form urn:agsc:channel:<name>:<source_id>, which the schema admits alongside https?://. [PRD-056]
  • AGSC-01-34 Attachments live under content/attachments/<slug>/ and nowhere else; a file there that no item's attachments[] names is an orphan warning (AGSC-E414); an attachments[] entry whose file is absent, or whose bytes do not match the SHA-256 recorded for it, is AGSC-E413 at build; the byte comparison — the served file against the SHA-256 in the served pages/<slug>.jsonld (AGSC-05-29) — is a verify check over a published node and reports AGSC-E413 there. agsc.config.json gains the OPTIONAL attachments{max_bytes} (default 1048576, maximum 10485760, x- admitted, AGSC-11-01); a larger file is AGSC-E904. [AGSC-01-16]
  • AGSC-01-35 Every relative path a Bundle carries as the value of a key — attachments[].file, diagram.file, build.out — MUST be a sequence of /-separated segments in which no segment is .. or ., which does not begin with /, does not contain a \ or a U+0000, and which resolves inside the Bundle root; a violation is AGSC-E902. An inline Markdown link or image target in a body is held to the same rule except that it MAY contain .. segments, because an item under content/<type-plural>/ cannot otherwise reach content/assets/ at all (AGSC-02-95, AGSC-03-11): it MUST NOT begin with /, MUST NOT contain a \ or a U+0000, and the path it resolves to — relative to the file that carries it — MUST lie inside the Bundle root. For a body reference the escape test wins over the segment test. A body target that escapes the Bundle root is AGSC-E902; a body target inside the Bundle root that resolves to no item, asset or anchor is AGSC-E310 (AGSC-03-11), never AGSC-E902. The schemas check only the cheap syntactic part (no leading /, no \, no NUL anywhere), because the segment rule cannot be expressed as a portable regular expression: a lookahead is valid in ECMAScript but uncompilable in RE2, Go and Rust, and the vectors promise ports in any language. This rule is the normative form of that segment test. (Amended 2026-10-10 for 1.0.0: the prohibition on a leading / is written with the key word in capitals) [AGSC-01-16]

1.8 Agent lane configuration

  • AGSC-01-36 agents[] is an OPTIONAL array of agent-lane declarations, each {name, kind, author, operator, model, tasks[], types[], channel, schedule, budget_usd_month, max_new_items, max_claims, enabled}: name a slug unique within the array; kind ∈ llm|process; author the forge identity under which the lane's Proposals are opened (the same grammar as channels[].author); operator the accountable human, human:<id> (AGSC-02-07); model a non-empty string, REQUIRED when kind is llm, absent otherwise; tasks[] a non-empty subset of create, edit, update, review, summarize, translate, refresh, plan, claim, work; types[] a non-empty subset of concept, episode, lesson (default all three — a procedure, gate, cluster, configuration, workflow or schema is never in an agent lane, AGSC-08-26(b)); channel the name of a channels[] entry whose author equals the agent's author and whose publish choice and guards therefore govern the lane's Proposals (AGSC-01-31, AGSC-08-26); schedule an OPTIONAL string the host's scheduler interprets and this specification does not; budget_usd_month an integer ≥ 0, REQUIRED when kind is llm, and the sum of budget_usd_month over the entries with enabled: true MUST NOT exceed the node's budget.usd_month (AGSC-01-38) — a configuration that does is invalid with AGSC-E212; max_new_items an integer ≥ 1, default 20, the greatest number of items one Proposal of the lane may create (the bound on a runaway planner, AGSC-08-28(c)); max_claims an integer ≥ 1, default 1, the greatest number of tasks the lane may hold in TASK_STATE_WORKING at once (the work-in-progress limit of AGSC-10-17); enabled a boolean, default false. Each object admits x-<vendor>-<key> keys; any other unknown key is AGSC-E004; an enum violation is AGSC-E203. The object declares the lane; its behaviour is AGSC-08-28…30. [PRD-063]
  • AGSC-01-37 The environment file. Every value of agsc.config.json that is a secret or host-specific is configurable from the environment, and the environment is configurable from a file: a conforming tool MUST read, before anything else, an OPTIONAL .env file in the Bundle root — UTF-8, one NAME=value per line, # comments, no quoting or interpolation, a later line winning over an earlier one — and MUST take from it only names matching ^AGSC_[A-Z0-9_]+$, ignoring every other line; AGSC_FEATURE_LLM_REVIEW is read from the process environment only and never from .env, because no Bundle file may enable the review lane (AGSC-08-27) (Amended 2026-10-02 for 1.0.0: the exception was not stated); a name already present in the process environment keeps its process value (the precedence of AGSC-09-09 becomes flags > process environment > .env > project configuration > user configuration). Every scalar key of AGSC-01-18 is addressable as AGSC_ followed by its path in upper case with _ between segments (AGSC_BUDGET_USD_MONTH, AGSC_BUILD_OUT, AGSC_SITE_BASE), and the named entries of agents[] and channels[] as AGSC_AGENT_<NAME>_<KEY> and AGSC_CHANNEL_<NAME>_<KEY> with the slug in upper case and - as _ (AGSC_AGENT_EDITOR_ENABLED=true, AGSC_AGENT_EDITOR_BUDGET_USD_MONTH=3); a value is parsed by the schema type of the key it overrides (true/false, an integer, else a string) and a value that fails the schema is AGSC-E201…E204 as if written in the file. Model credentials are environment-only — AGSC_MODEL_API_KEY and, for an OpenAI-compatible endpoint, AGSC_MODEL_BASE_URL — and MUST NOT be configuration keys, so that no Bundle file ever holds a secret (AGSC-08-15). init MUST write .env into .gitignore and MUST write .env.example listing every recognised name with an empty value; a tracked .env — one present in the content branch — is AGSC-E403 (the secrets lint of AGSC-08-15) whatever it holds. The configuration input of the build function (AGSC-04-01) is the configuration as resolved after these overrides, and ci MUST print the names — never the values — of the overrides in effect, so that a reproduction can be set up from the log. [PRD-065, AGSC-09-09, NFR-11]
  • AGSC-01-38 The node-wide spend cap. budget{usd_month} is an integer ≥ 0, default 10, the most a node may spend on model calls of every kind in one calendar month — agent lanes (AGSC-08-28), the review lane (AGSC-08-27), automatic correction (AGSC-01-32), a narrating responder (AGSC-09-14a) and anything else that records usage — summed over every Episode of the month (AGSC-08-25); the sum of the enabled agents' budget_usd_month MUST NOT exceed it (AGSC-01-36, AGSC-E212); when it is reached every model-calling path MUST stop for the month with the warning AGSC-E510, and a tool that cannot compute the month's spend MUST NOT call a model (the rule of AGSC-01-32). The reference node keeps the default (NFR-11); AGSC_BUDGET_USD_MONTH overrides it per AGSC-01-37. [PRD-065, NFR-11]

1.9 Additions of 1.1

  • AGSC-01-39 SKOS import (adapter skos). import <file.ttl> --from skos reads one RDF 1.1 Turtle file that holds a SKOS thesaurus (SKOS Reference, W3C Recommendation of 18 August 2009, https://www.w3.org/TR/skos-reference/) and writes items under AGSC-01-22 and AGSC-01-23; it is an adapter in the sense of AGSC-01-26a. Subjects are taken in the code-point order of their IRIs, and the mapping is this. (a) Each skos:Concept becomes a concept item with kind: term; its slug is the slug of its title by the rule of AGSC-02-91, suffixed -2, -3, … on a collision (AGSC-01-23). (b) title is the skos:prefLabel whose language tag equals i18n.default (compared case-insensitively), else the untagged one, else the one whose tag is least in code-point order (tags compared case-insensitively; two labels with one tag, the lexically least), clipped or replaced as AGSC-02-90 does; a concept with no prefLabel takes the last segment of its IRI as its title; every other prefLabel is dropped. (c) Each skos:altLabel is a value of aliases[], without duplicates and without the title, in code-point order; a SKOS-XL label (skosxl:prefLabel, skosxl:altLabel) is read as its skosxl:literalForm and flattened the same way, and the label resource is dropped. (d) The skos:definition that is least in code-point order of its lexical form (ties broken by language tag) is the description when it has 40 to 200 code points; otherwise it is written as the first paragraph of the body, no description is written and one warning AGSC-E506 names the concept; every further definition is dropped. (e) skos:broader, skos:narrower and skos:related between two concepts of the file become the Links of the same names (AGSC-03-01); one whose object is not a concept of the file is dropped. (f) Each skos:ConceptScheme, skos:Collection and skos:OrderedCollection becomes a cluster item; a concept that is skos:inScheme, skos:topConceptOf or a skos:member of one carries its slug in clusters[], in code-point order; a collection that is a skos:member of another becomes a cluster whose broader is that collection, and where it is a member of several collections the first in code-point order of the IRI of the collection is its broader and every other membership is dropped (AGSC-02-17). (g) Each dcterms:source whose object is an http or https IRI becomes a sources[] entry with that resource; any other object is dropped. (h) The concept's own IRI is kept in the member x-skos-iri, and a dcterms:license of its scheme in x-skos-license; both are preserved under AGSC-02-05a. (i) prov is written as AGSC-01-22 writes it, and every item is a draft (AGSC-01-22). Dropped: notation, every note property (skos:note, skos:scopeNote, skos:historyNote, skos:editorialNote, skos:changeNote, skos:example), the order of an ordered collection, the mapping properties (skos:exactMatch, skos:closeMatch, skos:broadMatch, skos:narrowMatch, skos:relatedMatch), and every statement about a class, an individual or a shape; every statement that none of (a) to (i) uses, and every value that (b) to (g) drop, MUST be reported as one warning AGSC-E506 naming its subject and predicate. The adapter MUST be idempotent (AGSC-01-23): a second run over the same file changes nothing. The cases imp-0006, imp-0007 and imp-0008 pin the mapping, the drops and the idempotence. (Amended 2026-10-29 for 1.1.0: rule added for 1.1.0: the SKOS import mapping, which 1.0 did not specify) [SKOS, AGSC-01-22, AGSC-01-26a]
  • AGSC-01-40 Names and paths that only some file systems refuse. From 1.1 lint, build and ci MUST report each of the following as the warning AGSC-E423, naming the file, and MUST NOT refuse the Bundle for it (AGSC-00-14): (a) a path segment of a file of the Bundle whose part before the first . equals, after ASCII lower-casing, one of the Windows device names con, prn, aux, nul, com1 to com9 and lpt1 to lpt9, and the superscript forms com¹, com², com³, lpt¹, lpt² and lpt³ (a slug such as con matches the grammar of AGSC-01-10, and Windows treats con.md as the device); (b) two paths under content/attachments/ or content/assets/ that are equal after NFC, then upper-casing, then lower-casing by the default case mappings of Unicode (so ß equals ss), reported on each path of the group except the first in code-point order; (c) a file path relative to the Bundle root longer than 200 code points, which leaves room for the folder a Windows checkout sits in under the legacy limit of 260 characters; (d) a path segment that ends in a space or a period, or that contains one of <, >, :, ", |, ? and *; (e) in any string of the files that lint reads (front-matter values and member names, body text and configuration), a Unicode noncharacter, which AGSC-04-05 reports as AGSC-E423. The reserved names, characters and the limit are those of the page "Naming Files, Paths, and Namespaces" of Microsoft Learn (page dated 2024-08-28, updated 2025-04-11, read 2026-10-29). The cases bundle-0013, bundle-0014 and bundle-0015 pin (a) to (c); (e) is pinned by bundle-0021; (d) has no case because a file name that Windows refuses cannot be checked out where the case would also run. (Amended 2026-10-29 for 1.1.0: rule added for 1.1.0: warnings for names and paths that only some file systems refuse; none is refused) (Amended 2026-11-10 for 1.1.0: the case comparison is named as the engine makes it, NFC, then upper-casing, then lower-casing, where "Unicode simple case folding" was written; the two differ for ß and a few other letters, the engine is unchanged so no 1.0 result moves, and lint-0064 pins ß equal to ss) [Windows file naming, AGSC-01-10, AGSC-01-35]
  • AGSC-01-41 The domain layer: configuration. domain is an OPTIONAL object of agsc.config.json with four OPTIONAL members. vocabulary is a relative path (AGSC-01-35) to a Turtle file holding the node's own classes and relations (AGSC-05-38). shapes is a relative path to a Turtle file of SHACL shapes (AGSC-05-41). questions is a relative path to a JSON file of the node's competency questions (AGSC-05-41). contexts[] is an array of {cluster, namespace}: cluster the slug of a cluster item, namespace an absolute https: IRI that ends in # or /; a cluster and a namespace each occur at most once (AGSC-08-32). A path MUST NOT name content/, dist/ or build.out, or a path under one of them, as AGSC-01-19 requires of build.out; such a path is AGSC-E204. A named file that is absent is AGSC-E901; a cluster that names no cluster item is AGSC-E301; a repeated cluster or namespace, or a namespace outside the form, is AGSC-E209. The files are inputs read by lint, build, verify and ci; they are no route and are not copied into build.out. The case bundle-0020 pins AGSC-E901 and AGSC-E301. A node uses the domain layer when domain.vocabulary is present and declares contexts when domain.contexts is not empty. A node that sets shapes or questions without vocabulary is valid: its invariants and questions run on the graph with no site classes (AGSC-05-41). A Bundle with no domain object whose items state no domain key (AGSC-02-25, AGSC-03-27) is a Bundle of 1.0 and every byte it emits is unchanged; a warrant adds its triples and its domain part on any node (AGSC-05-40). (Amended 2026-10-29 for 1.1.0: rule added for 1.1.0: the configuration of the optional domain layer) (Amended 2026-11-10 for 1.1.0: "and no domain key" added, because a warrant is read on any node (AGSC-05-40, graph-0045), so a node with a warrant and no domain object carries the domain part in its page scripts and tool answers) (Amended 2026-11-11 for 1.1.0: the trace bracket names PRD-076, the requirement of the domain layer.) [design, AGSC-01-18, PRD-076]

  • AGSC-01-42 The diagram source grammar and its compiled bytes. A writer that compiles content/diagrams/<slug>.diagram (AGSC-01-07) MUST accept exactly the language below and, for a source it accepts, MUST produce exactly the bytes below, <slug> being the slug of the item that carries the diagram (AGSC-02-13). A source it does not accept yields no SVG and the finding AGSC-E412, the registered code of a diagram that cannot be compiled (AGSC-02-13, AGSC-02-98); a source longer than 1,048,576 code points is AGSC-E904.

    Lines and tokens. On each line everything from the first # to the end of the line is a comment — a # inside a quoted string starts one too — and the rest is trimmed of spaces; an empty result is skipped. A line is split into tokens at each U+0020 outside double quotes; a double quote toggles quoting and is dropped; an empty quoted string yields no token; there is no escape. The first token is the statement name, and every argument is one token, so that a text with a space in it is quoted. A number is a token that ECMAScript Number() converts to a finite value. A flag is a token equal to its name, looked for among all the tokens of the statement, so that a text argument equal to a flag name sets the flag too, which an author SHOULD avoid. In a box or circle label a | starts a new line of text.

    Statements — these twelve and no other; any other first token is AGSC-E412:

    statementargumentsflags
    canvasW H, both greater than 0; the default is 460 260—
    labelTEXT, not empty: the accessible name when the item gives none; the last one wins—
    boxID X Y W H [TEXT]acc dashed
    circleID CX CY R [TEXT]acc dashed
    regionID X Y W H [CAPTION]—
    arrowFROM TOvia=X,Y;X,Y… both dashed acc rel=KEY
    lineX1 Y1 X2 Y2acc dashed thick rel=KEY
    pathDarrow acc dashed
    textX Y STRINGsize=N (default 11) left right rel=KEY
    crossX Y—
    noteTEXT, not empty; the last one wins—
    barX Y Wthick

    Refusals, each AGSC-E412 naming the line: a duplicate ID among boxes, circles and regions; a box whose corners lie outside the canvas; an arrow naming an ID that no earlier statement defined; a via that is not a list of number pairs; two arrows whose resolved paths are equal, once a waypoint on the straight line is dropped and direction is ignored; an arrow without via whose two shapes have the same centre, which gives the line no direction; acc on any number of statements other than one; acc together with thick on one statement, which would write stroke-width twice; two shapes other than regions whose rectangles overlap, an ID that begins with _ being left out of the comparison; with a note, a shape other than a region whose lower edge lies below height − 26; a rel= value that is none of the fourteen Link keys of AGSC-03-01. A writer MAY also refuse a text or note that its own measure of text width finds too wide for the canvas, leaving 4 px for a text and 16 px either side for a note; that measure is not pinned, and the bytes of an accepted source are.

    Numbers and escaping. A number is written rounded to the nearest tenth as ECMAScript Math.round(n * 10) / 10 computes it, -0 as 0, with one decimal place and a trailing .0 dropped. Text is escaped by replacing &, <, > and " with &amp;, &lt;, &gt; and &quot;, and nothing else.

    Elements. Each statement adds to a draw list and a text list, both kept in source order. ACC is class="agsc-accent" stroke-width="2.2" when acc is set; when rel=KEY is set as well the class value is agsc-accent agsc-rel-KEY, and when rel is set without acc the whole of ACC is class="agsc-rel-KEY". DASH(n m) is stroke-dasharray="n m" when dashed is set. MARK is url(#<slug>-arrow).

    In text elements the line i of n lines at font size s stands at y₀ − (n − 1)(s + 4)/2 + i(s + 4). A text element is written <text x="…" y="…" font-size="s">…</text>; for box, circle, region and note the attributes are exactly those three. An arrow runs between the rectangles of its two shapes (a circle's is its bounding square): without via the path is M p1 L p2, where b1 and b2 are the points at which the segment between the two centres leaves the first and enters the second rectangle (the segment is scaled by the smaller of half-width over |dx| and half-height over |dy|, a zero difference counting as unbounded), and p1, p2 are b1, b2 moved 4 px towards each other along the segment; with via the path is M p1 L v1 L v2 … L p2, p1 being the point where the segment from the first centre to v1 leaves the first rectangle and p2 the point where the segment from the last waypoint to the second centre enters the second.

    The document is, with LF line ends and one LF at the end, <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 W H" role="img" aria-labelledby="<slug>-title <slug>-desc" font-family="system-ui, sans-serif" font-size="14">, then the lines <title id="<slug>-title">LABEL</title>, <desc id="<slug>-desc">DESC</desc>, <defs><marker id="<slug>-arrow" viewBox="0 0 10 10" refX="9" refY="5" markerWidth="7" markerHeight="7" orient="auto-start-reverse"><path d="M0 0 L10 5 L0 10 z" fill="currentColor"/></marker></defs>, <g fill="none" stroke="currentColor" stroke-width="1.5">, the draw elements each on a line indented four spaces (one line of four spaces when there are none), </g>, <g fill="currentColor" text-anchor="middle">, the text elements likewise, </g> and </svg>. LABEL is diagram.alt when the item gives one (AGSC-02-13), else the last label statement, else <slug> diagram; DESC is the note when there is one, else LABEL.
